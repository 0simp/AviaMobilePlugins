All my plugins for [Avia Client Mobile](https://github.com/0simp/AviaClientMobile)

Plugins marked as (REDUNDANT) are no longer needed because their functionality exists in either normal stoat or avia mobile and will therefore not receive updates

Plugins marked as (DISCONTINUED) will no longer recieve updates, either because they have been replaced by something else or because I can't be bothered

# 3TapReply (REDUNDANT)

Allows you to reply to a message by tapping it 3 times. This plugin is now integrated into avia mobile

# BetterScrollLock

Prevents you from accidentally clicking the home button while the scroll lock is active. This plugin will be integrated in the next avia mobile update

# MobileCSSPlus (REDUNDANT)

Mobile optimised version of [Monaco CSS](https://raw.githubusercontent.com/AvaLilac/Ava-s-AviaClient-Plugins/refs/heads/main/QuickCSSPlus.js). Adds a clear and paste button because select all and paste functions don't work in the editor on mobile. This plugin is now integrated into avia mobile

# ShiftNewLine (REDUNDANT)

Makes holding shift and enter insert a new line in your message instead of sending it. Small issue: it moves your cursor to the beginning of the text so you have to move it back manually. This plugin is now integrated into avia mobile
